# Wayfarer Pixel Asset Pack

Generated as a cohesive first-pass pixel art set for the current playable game.

- `wayfarer-walk-sheet.png`: 4x4 directional explorer walk sheet.
- `kestrel.png`: right-facing Kestrel ship sprite with transparency.
- `thalassa-environment-sheet.png`: flora, rock, crystal, and tree atlas.
- `thalassa-grass.png`: seamless-looking grass terrain texture.

Render sprite assets with image smoothing disabled to retain hard pixel edges.
